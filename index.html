کتاب جامع و حرفه‌ای CSS

این کتاب با هدف آموزش CSS از سطح کاملاً مقدماتی تا سطح حرفه‌ای طراحی شده است.

در این کتاب صرفاً نام Propertyها یا چند مثال کوتاه ارائه نمی‌شود. برای هر مبحث تلاش می‌شود مفهوم، Syntax، مقدارها، مثال، کاربرد، نکات حرفه‌ای و اشتباهات رایج بررسی شود.

روش مطالعه:

مثال‌های CSS را فقط نخوان. آن‌ها را در VS Code بنویس، در مرورگر اجرا کن و مقدارها را تغییر بده تا رفتار CSS را به‌صورت عملی یاد بگیری.

بخش ۱

مبانی CSS

CSS چیست؟

CSS مخفف Cascading Style Sheets است. CSS زبان مورد استفاده برای تعیین ظاهر، Layout و نحوه نمایش عناصر HTML است.

CSS چه کارهایی انجام می‌دهد؟

  • رنگ عناصر را تعیین می‌کند.
  • اندازه عناصر را کنترل می‌کند.
  • فاصله‌ها را کنترل می‌کند.
  • فونت و Typography را کنترل می‌کند.
  • Layout صفحه را می‌سازد.
  • صفحات Responsive ایجاد می‌کند.
  • Animation و Transition ایجاد می‌کند.
  • ظاهر فرم‌ها را کنترل می‌کند.
CSS فقط برای رنگ و زیباسازی نیست. بخش مهمی از CSS مربوط به Layout، Rendering، Responsive Design و رفتار عناصر در صفحه است.
فصل ۱

Syntax و ساختار CSS 

selector {

    property: value;

}

Selector چیست؟

Selector مشخص می‌کند که قانون CSS روی کدام عنصر یا عناصر اعمال شود.

Property چیست؟

Property ویژگی‌ای است که می‌خواهیم تغییر دهیم.

Value چیست؟

Value مقدار Property است.

مثال کامل 

.title {

    color: blue;

    font-size: 30px;

    font-weight: 700;

}

در مثال بالا:

  • .title یک Class Selector است.
  • color یک Property است.
  • blue مقدار Property است.
  • font-size Property دیگری است.

Cascade

Cascade فرآیندی است که مرورگر از طریق آن تصمیم می‌گیرد در صورت وجود چند Declaration قابل اعمال، کدام مقدار نهایی استفاده شود. 

p {

    color: blue;

}


p {

    color: red;

}

در شرایط یکسان، Declaration بعدی برنده می‌شود؛ اما Cascade فقط به ترتیب نوشتن محدود نیست. Origin، Importance، Cascade Layers و Specificity نیز اهمیت دارند.

فصل ۴

Specificity

Specificity میزان اختصاصی بودن یک Selector را مشخص می‌کند. 

p {

    color: blue;

}


.text {

    color: red;

}


#title {

    color: green;

}

به‌صورت مفهومی، Selector دارای ID معمولاً از Selector دارای Class اختصاصی‌تر است و Class نیز از Type Selector اختصاصی‌تر است.

توصیه حرفه‌ای: برای حل مشکلات CSS دائماً Specificity را افزایش نده. Selectorهای بیش از حد پیچیده، نگهداری پروژه را سخت می‌کنند.

Global Values

مقدار مفهوم

Property: display

مفهوم

Property مربوط به display نحوه قرارگیری و رفتار عنصر در سیستم Layout را مشخص می‌کند.

مقدارهای مهم

مقدار مفهوم
block عنصر رفتار Block-level دارد.
inline عنصر در جریان Inline قرار می‌گیرد.
inline-block رفتار Inline را با ویژگی‌های Box مانند width و height ترکیب می‌کند.
flex عنصر Flex Container می‌شود.
inline-flex Flex Container با رفتار Inline.
grid عنصر Grid Container می‌شود.
inline-grid Grid Container با رفتار Inline.
flow-root یک Block Formatting Context جدید ایجاد می‌کند.
contents Box اصلی عنصر در Layout حذف می‌شود ولی محتوای آن می‌تواند در Layout شرکت کند.
none عنصر در Layout نمایش داده نمی‌شود.

مثال Flex

    display:
        flex;

    justify-content:
        center;

    align-items:
        center;

    gap:
        20px;

}
نکته: display: none فقط عنصر را از Layout خارج می‌کند؛ این با visibility: hidden یکسان نیست.

object-fit و object-position

object-fit چیست؟

Property مربوط به object-fit مشخص می‌کند یک تصویر یا ویدئو چگونه داخل Box خودش قرار بگیرد. این Property زمانی بسیار مهم است که برای عنصر تصویر، width و height مشخص کرده باشیم اما نسبت تصویر اصلی با Box متفاوت باشد.

Syntax 

img {

    object-fit: value;

}

مقدارهای object-fit

مقدار توضیح مثال
fill مقدار پیش‌فرض است. تصویر تمام فضای Box را پر می‌کند اما اگر نسبت تصویر متفاوت باشد، ممکن است تصویر کشیده یا فشرده شود. 
img {

    object-fit:
        fill;

}
contain کل تصویر بدون برش داخل Box قرار می‌گیرد. ممکن است در اطراف تصویر فضای خالی ایجاد شود. 
img {

    object-fit:
        contain;

}
cover تصویر تمام Box را پر می‌کند. نسبت تصویر حفظ می‌شود، اما ممکن است بخشی از تصویر برش بخورد. 
img {

    object-fit:
        cover;

}
none اندازه اصلی تصویر حفظ می‌شود و تصویر متناسب با Box تغییر اندازه نمی‌دهد. 
img {

    object-fit:
        none;

}
scale-down مرورگر بین none و contain کوچک‌ترین حالت مناسب را انتخاب می‌کند. 
img {

    object-fit:
        scale-down;

}

Float و Clear

Float چیست؟

Property مربوط به float یکی از قابلیت‌های قدیمی و مهم CSS برای جابه‌جایی یک عنصر به سمت چپ یا راست و اجازه دادن به محتوای اطراف برای قرار گرفتن در کنار آن است.

یکی از کاربردهای کلاسیک float قرار دادن تصویر در کنار متن است.

Syntax 

.image {

    float:
        right;

}

مقدارهای float

مقدار توضیح
none مقدار پیش‌فرض است. عنصر به صورت Float قرار نمی‌گیرد و در جریان معمول Layout باقی می‌ماند.
left عنصر را به سمت چپ Container خودش منتقل می‌کند. محتوای Inline اطراف عنصر می‌تواند در فضای باقی‌مانده کنار آن قرار بگیرد.
right عنصر را به سمت راست Container خودش منتقل می‌کند.
inline-start عنصر را به سمت ابتدای Inline Axis منتقل می‌کند. این مقدار برای Layoutهایی که Direction متفاوت دارند مفید است.
inline-end عنصر را به سمت انتهای Inline Axis منتقل می‌کند.

float: left 

.image {

    float:
        left;

}

در این حالت عنصر به سمت چپ حرکت می‌کند و محتوای اطراف می‌تواند در فضای باقی‌مانده در کنار آن قرار بگیرد.

float: right 

.image {

    float:
        right;

}

این روش برای قرار دادن تصویر در سمت راست متن، مخصوصاً در صفحات فارسی، می‌تواند کاربرد داشته باشد.

مثال کاربردی: تصویر کنار متن 

<img
    class="article-image"
    src="image.jpg"
    alt="تصویر مقاله"
>

<p>

    این یک متن نمونه است که در کنار تصویر
    قرار می‌گیرد و فضای باقی‌مانده را پر می‌کند.

</p>
.article-image {

    width:
        250px;

    float:
        right;

    margin-left:
        20px;

    margin-bottom:
        10px;

}
نکته: یکی از کاربردهای تاریخی و معروف float همین قرار دادن تصویر در کنار متن است. برای ساخت Layoutهای پیچیده امروزی، معمولاً Flexbox و Grid انتخاب مناسب‌تری هستند.

Float چه اتفاقی در Layout ایجاد می‌کند؟

وقتی یک عنصر Float می‌شود، رفتار آن نسبت به جریان معمول صفحه تغییر می‌کند. عناصر Block بعدی ممکن است در فضای باقی‌مانده کنار عنصر Float قرار بگیرند، در حالی که محتوای Inline مانند متن می‌تواند اطراف آن جریان پیدا کند. 

.image {

    float:
        left;

    width:
        200px;

}

clear چیست؟

Property مربوط به clear مشخص می‌کند که یک عنصر اجازه داشته باشد در کنار عناصر Float قرار بگیرد یا باید از کنار آن‌ها خارج شود.

Syntax 

.element {

    clear:
        value;

}

مقدارهای clear

مقدار توضیح
none مقدار پیش‌فرض است. عنصر می‌تواند در کنار عناصر Float قرار بگیرد.
left عنصر را از کنار Floatهای سمت چپ خارج می‌کند.
right عنصر را از کنار Floatهای سمت راست خارج می‌کند.
both عنصر را از کنار Floatهای چپ و راست خارج می‌کند.
inline-start عنصر را از کنار Floatهای سمت ابتدای Inline Axis خارج می‌کند.
inline-end عنصر را از کنار Floatهای سمت انتهای Inline Axis خارج می‌کند.

مثال clear: both 

.footer {

    clear:
        both;

}

در این حالت Footer از کنار Floatهای سمت چپ و راست خارج می‌شود و بعد از محدوده Floatها قرار می‌گیرد.

مشکل ارتفاع والد در Float

یکی از مشکلات معروف Float این است که عناصر Float ممکن است در محاسبه ارتفاع معمول والد مانند عناصر عادی جریان صفحه رفتار نکنند. 

.parent {

    background:
        #eee;

}

.child {

    float:
        left;

    width:
        200px;

}

ممکن است والد بدون ارتفاع مورد انتظار دیده شود؛ چون محتوای Float شده در جریان معمول ارتفاع‌دهی والد به شکل عناصر عادی قرار نمی‌گیرد.

روش قدیمی Clearfix

یکی از روش‌های قدیمی برای حل مشکل ارتفاع والد استفاده از clearfix بود. 

.clearfix::after {

    content:
        "";

    display:
        table;

    clear:
        both;

}

این تکنیک باعث می‌شود یک Pseudo-element بعد از محتوای Float ایجاد شود و Floatها را Clear کند.

روش مدرن: flow-root

در CSS مدرن می‌توان برای ایجاد یک Block Formatting Context جدید از display: flow-root استفاده کرد. 

.parent {

    display:
        flow-root;

}
نکته حرفه‌ای: در پروژه‌های جدید، اگر هدف فقط حل مشکل خروج Float از محدوده والد باشد، flow-root معمولاً راه‌حل تمیزتری نسبت به تکنیک‌های قدیمی Clearfix است.

تفاوت Float و Flexbox

Float Flexbox
تکنولوژی قدیمی‌تر برای Layout سیستم Layout مدرن
مناسب برای جریان متن اطراف تصویر مناسب برای Layout یک‌بعدی
کنترل Layout محدودتر کنترل بسیار بیشتر روی Alignment
نیاز به clear در برخی Layoutها معمولاً نیازی به clear ندارد

تفاوت Float و Grid

Float برای ساخت سیستم‌های Grid مدرن انتخاب مناسبی نیست. CSS Grid برای ساخت Layoutهای دوبعدی طراحی شده و کنترل دقیق‌تری روی سطرها و ستون‌ها ارائه می‌دهد. 

.layout {

    display:
        grid;

    grid-template-columns:
        1fr 1fr;

    gap:
        20px;

}

        alt="تصویر مقاله"
    >

    </h2>

    <p>

        و می‌تواند در کنار تصویر جریان داشته باشد.

    </p>

    <div class="article-end"></div>

</article>

جمع‌بندی Float و Clear

  • float عنصر را در سمت مشخصی قرار می‌دهد.
  • clear اجازه قرار گرفتن عنصر در کنار Float را کنترل می‌کند.
  • Float برای جریان متن اطراف تصاویر همچنان کاربرد دارد.
  • برای Layoutهای مدرن معمولاً Flexbox و Grid انتخاب مناسب‌تری هستند.
  • flow-root یکی از روش‌های مدرن برای مدیریت Formatting Context است.
حالا با Float و Clear آشنا شدی و می‌توانی تفاوت آن‌ها را با سیستم‌های Layout مدرن مانند Flexbox و Grid درک کنی.

مرجع حرفه‌ای Property های CSS

در این بخش Property های مهم CSS به‌صورت مرجع بررسی می‌شوند. برای هر Property ابتدا مفهوم آن، سپس Syntax، مقدارهای اصلی، کاربرد و مثال عملی ارائه می‌شود.

1. color

Property مربوط به color رنگ متن عنصر را مشخص می‌کند. این Property معمولاً روی محتوای متنی اعمال می‌شود و مقدار آن می‌تواند از انواع مختلف رنگ CSS استفاده کند.

Syntax 

color: مقدار;

مقدارهای قابل استفاده

مقدار توضیح مثال
نام رنگ استفاده از نام‌های استاندارد رنگ CSS. color: red;
Hex تعیین رنگ با سیستم hexadecimal. color: #ff0000;
RGB تعیین رنگ بر اساس Red، Green و Blue. color: rgb(255 0 0);
RGBA / Alpha رنگ همراه با میزان شفافیت. color: rgb(255 0 0 / 50%);
HSL رنگ بر اساس Hue، Saturation و Lightness. color: hsl(0 100% 50%);
currentColor از مقدار فعلی color عنصر استفاده می‌کند. color: currentColor;
transparent رنگ کاملاً شفاف. color: transparent;
inherit مقدار color را از والد دریافت می‌کند. color: inherit;
initial مقدار اولیه Property را اعمال می‌کند. color: initial;
unset بسته به وضعیت Property مانند inherit یا initial رفتار می‌کند. color: unset;

    color: #2563eb;

}

    color: rgb(71 85 105);

    color: currentColor;

}

initial مقدار اولیه Property را اعمال می‌کند.
unset بر اساس قواعد Inheritance مانند inherit یا initial رفتار می‌کند.
revert مقدار را به رفتار قبلی Cascade برمی‌گرداند.
revert-layer مقدار مناسب را از Cascade Layer قبلی می‌گیرد.

اشتباهات رایج Padding

  1. استفاده از Padding منفی.
    مقدار منفی برای Padding معتبر نیست.
  2. فراموش کردن box-sizing هنگام تعیین Width و Height.
  3. استفاده از Padding برای ایجاد فاصله بین چند عنصر مستقل.
  4. استفاده بیش از حد از padding-top و padding-left در Layoutهای RTL/LTR.
  5. استفاده از Padding ثابت بزرگ در همه اندازه‌های صفحه. در طراحی Responsive بهتر است گاهی از واحدهای نسبی و clamp() استفاده شود.
جمع‌بندی فصل Padding

Padding فضای داخلی بین Content و Border است. می‌تواند یک تا چهار مقدار داشته باشد و از واحدهای طولی و درصدی استفاده کند. Padding برخلاف Margin نمی‌تواند مقدار منفی داشته باشد. همچنین در طراحی مدرن، استفاده از Logical Properties مانند padding-inline و padding-block باعث می‌شود کد برای RTL و LTR انعطاف‌پذیرتر باشد.

فصل ۳۵

Property: width

width چیست؟

Property مربوط به width برای تعیین اندازه افقی یک عنصر در محور Inline استفاده می‌شود.

به زبان ساده، Width مشخص می‌کند یک عنصر تا چه اندازه فضای افقی در اختیار داشته باشد.

نکته مهم:

Width همیشه به معنی «عرض نهایی قابل مشاهده عنصر» نیست. مقدار نهایی به عواملی مانند box-sizing، Padding، Border، Layout و محدودیت‌های min-width و max-width نیز بستگی دارد.

Syntax 

selector {

    width: value;

}

مقدار width می‌تواند از انواع مختلفی باشد؛ از جمله:

  • مقدارهای طولی مانند px
  • درصد مانند %
  • مقدارهای مبتنی بر Viewport
  • مقدارهای مخصوص Layout
  • مقدارهای Global
  • توابع CSS مانند calc() و min() و max() و clamp()

مقدار px 

.box {

    width:
        300px;

}

در این مثال Width عنصر برابر 300px تعیین شده است.

استفاده از px برای اندازه‌های ثابت مفید است؛ اما اگر همه Widthهای سایت را به صورت ثابت تعیین کنیم، Responsive Design سخت‌تر می‌شود.

مقدار % 

.container {

    width:
        80%;

}

درصد معمولاً نسبت به اندازه مربوطه در کانتینر شامل محاسبه می‌شود.

مثال 

.parent {

    width:
        1000px;

}


.child {

    width:
        50%;

}

در این مثال، در شرایط معمول، عرض فرزند می‌تواند برابر با ۵۰٪ از عرض مرجع خود باشد.

مقدار auto 

.box {

    width:
        auto;

}

مقدار auto به مرورگر اجازه می‌دهد Width را بر اساس قواعد Layout تعیین کند.

نکته:

مقدار اولیه Width در CSS معمولاً auto است. بنابراین در بسیاری از عناصر Block اگر Width تعیین نشود، عنصر می‌تواند فضای موجود را طبق قواعد Layout پر کند.

واحد vw 

.hero {

    width:
        100vw;

}

واحد vw نسبت به عرض Viewport محاسبه می‌شود.

به صورت مفهومی: 

1vw = 1% از عرض Viewport
هشدار مهم در Responsive:

استفاده مستقیم از 100vw گاهی می‌تواند باعث ایجاد Overflow افقی شود؛ مخصوصاً زمانی که Viewport و Scrollbar در محاسبه متفاوت باشند. در بسیاری از Layoutها width: 100% انتخاب ساده‌تر و مناسب‌تری است.

استفاده از min() 

.container {

    width:
        min(
            90%,
            1200px
        );

}

تابع min() کوچک‌ترین مقدار محاسبه‌شده را انتخاب می‌کند.

این الگو یکی از روش‌های بسیار رایج برای ساخت Containerهای Responsive است.

استفاده از max() 

.box {

    width:
        max(
            300px,
            50%
        );

}

تابع max() بزرگ‌ترین مقدار محاسبه‌شده را انتخاب می‌کند.

استفاده از clamp() 

.container {

    width:
        clamp(
            300px,
            80vw,
            1200px
        );

}

ساختار کلی clamp() به صورت زیر است: 

clamp(
    minimum,
    preferred,
    maximum
)

مقدار Width نمی‌تواند از حداقل کمتر یا از حداکثر بیشتر شود، در حالی که مقدار ترجیحی می‌تواند بر اساس شرایط صفحه تغییر کند.

استفاده از calc() 

.content {

    width:
        calc(
            100% - 40px
        );

}

calc() اجازه می‌دهد عملیات محاسباتی بین مقدارهای CSS انجام دهیم.

مثال حرفه‌ای 

.sidebar {

    width:
        280px;

}


.main {

    width:
        calc(
            100% - 280px
        );

}

ارتباط width با min-width 

.box {

    width:
        50%;

    min-width:
        300px;

}

min-width حداقل Width مجاز عنصر را مشخص می‌کند. بنابراین حتی اگر Width اصلی کمتر شود، عنصر نمی‌تواند از حداقل تعیین‌شده کوچک‌تر شود؛ مگر اینکه قواعد دیگر Layout نتیجه متفاوتی ایجاد کنند.

ارتباط width با max-width 

.container {

    width:
        100%;

    max-width:
        1200px;

}

این الگو یکی از مهم‌ترین الگوهای طراحی Responsive است.

الگوی بسیار رایج:

width: 100%;
max-width: 1200px;
margin-inline: auto;

نتیجه: عنصر در صفحه‌های کوچک فضای موجود را استفاده می‌کند و در صفحه‌های بزرگ بیش از 1200px نمی‌شود.

Width و box-sizing

content-box 

.box {

    width:
        300px;

    padding:
        20px;

    border:
        5px solid black;

    box-sizing:
        content-box;

}

در حالت content-box، Width مربوط به Content است. بنابراین Padding و Border می‌توانند به اندازه نهایی Box اضافه شوند.

border-box 

.box {

    width:
        300px;

    padding:
        20px;

    border:
        5px solid black;

    box-sizing:
        border-box;

}

در حالت border-box، Width تعیین‌شده شامل Content، Padding و Border می‌شود.

Width در عناصر Block 

div {

    width:
        500px;

}

عناصر Block معمولاً می‌توانند Width مشخص دریافت کنند. اگر Width برابر auto باشد، رفتار آنها بر اساس فضای موجود و قواعد Block Layout تعیین می‌شود.

Width در عناصر Inline 

span {

    display:
        inline;

    width:
        300px;

}

Width و Height به شکل معمول روی یک عنصر Inline اعمال نمی‌شوند.

اگر نیاز داشته باشیم یک عنصر Inline Width و Height مشخص داشته باشد، می‌توانیم رفتار آن را تغییر دهیم: 

span {

    display:
        inline-block;

    width:
        300px;

}

Width در Flexbox 

.container {

    display:
        flex;

}


.item {

    width:
        300px;

}

در Flexbox، مقدار Width می‌تواند در محاسبه اندازه Flex Item نقش داشته باشد؛ اما Flexbox ممکن است بر اساس flex-grow، flex-shrink و flex-basis اندازه نهایی را تغییر دهد.

مثال 

.item {

    width:
        300px;

    flex:
        0 1 300px;

}

Width در CSS Grid 

.grid {

    display:
        grid;

    grid-template-columns:
        repeat(
            3,
            1fr
        );

}

در Grid معمولاً اندازه ستون‌ها توسط Trackها تعیین می‌شود. بنابراین همیشه لازم نیست برای هر Grid Item یک Width ثابت تعیین کنیم.

مثال حرفه‌ای 

.grid {

    display:
        grid;

    grid-template-columns:
        repeat(
            auto-fit,
            minmax(
                250px,
                1fr
            )
        );

}

مقدار توضیح
inherit مقدار Width را از عنصر والد به ارث می‌برد.
initial مقدار اولیه Property را اعمال می‌کند.
unset بر اساس قواعد Inheritance مانند inherit یا initial رفتار می‌کند.
revert مقدار را به رفتار قبلی Cascade برمی‌گرداند.

مثال عملی — Container حرفه‌ای 

.container {

    width:
        100%;

    max-width:
        1200px;

    margin-inline:
        auto;

    padding-inline:
        20px;

}

این الگو برای بسیاری از صفحات وب مناسب است. Width در صفحه‌های کوچک برابر فضای موجود است و max-width مانع بیش از حد بزرگ شدن Container می‌شود.

Width کاملاً Responsive 

.content {

    width:
        min(
            90%,
            1200px
        );

    margin-inline:
        auto;

}

این روش بدون نیاز به Media Query می‌تواند در بسیاری از Layoutها عملکرد مناسبی داشته باشد.

اشتباهات رایج در استفاده از width

  1. استفاده از Width ثابت برای تمام اندازه‌های صفحه.
  2. استفاده بی‌دلیل از width: 100vw و ایجاد Overflow افقی.
  3. فراموش کردن max-width برای Containerهای بزرگ.
  4. تعیین Width برای عناصر Flex و Grid بدون توجه به قواعد Layout آنها.
  5. تصور اینکه Width همیشه برابر با اندازه نهایی Border Box است.
  6. نادیده گرفتن box-sizing.

الگوی حرفه‌ای پیشنهادی 

.container {

    width:
        min(
            100% - 32px,
            1200px
        );

    margin-inline:
        auto;

}

این روش به جای اینکه Width را با چندین Media Query تغییر دهیم، اجازه می‌دهد Container بر اساس فضای موجود انعطاف‌پذیر باشد.

جمع‌بندی فصل Width

Property مربوط به width یکی از پایه‌ای‌ترین ابزارهای کنترل اندازه در CSS است. اما استفاده حرفه‌ای از آن فقط به نوشتن یک مقدار مانند 300px محدود نمی‌شود.

برای طراحی مدرن باید رابطه Width با min-width، max-width، box-sizing، Flexbox، Grid، calc()، min()، max() و clamp() را نیز درک کنیم.

فصل ۳۶

Property: height

height چیست؟

Property مربوط به height برای تعیین ارتفاع یک عنصر استفاده می‌شود. این Property یکی از مهم‌ترین ابزارهای کنترل اندازه عناصر در CSS است.

با این حال، استفاده حرفه‌ای از height نیازمند شناخت دقیق تفاوت بین ارتفاع ثابت، ارتفاع نسبی، ارتفاع محتوا و ارتفاع موجود در Layout است.

نکته بسیار مهم:

برخلاف چیزی که ممکن است در ابتدا تصور کنیم، تعیین height همیشه بهترین روش برای مشخص کردن ارتفاع یک عنصر نیست. در بسیاری از Layoutهای Responsive بهتر است اجازه دهیم ارتفاع عنصر بر اساس محتوا تعیین شود.

Syntax 

selector {

    height: value;

}

مقدار auto 

.box {

    height:
        auto;

}

مقدار auto به مرورگر اجازه می‌دهد ارتفاع عنصر را بر اساس شرایط Layout و محتوای آن تعیین کند.

این مقدار برای بسیاری از عناصر انتخاب مناسبی است؛ مخصوصاً زمانی که نمی‌خواهیم محتوای داخل عنصر بریده شود.

مقدار px 

.box {

    height:
        300px;

}

در این حالت ارتفاع مشخص و ثابتی برابر با 300px تعیین می‌شود.

اگر محتوای عنصر از ارتفاع تعیین‌شده بیشتر شود، ممکن است محتوا از Box خارج شود یا باعث Overflow شود. بنابراین Height ثابت باید با دقت استفاده شود.

مقدار درصدی % 

.parent {

    height:
        500px;

}


.child {

    height:
        50%;

}

در این مثال ارتفاع فرزند می‌تواند برابر با ۵۰٪ از ارتفاع مرجع خود باشد.

نکته بسیار مهم درباره درصد:

برای اینکه Height درصدی در بسیاری از شرایط به‌درستی محاسبه شود، باید ارتفاع مرجع آن مشخص باشد.

مثال اشتباه رایج 

.parent {

    height:
        auto;

}


.child {

    height:
        50%;

}

در چنین شرایطی ممکن است مرورگر نتواند درصد را نسبت به یک ارتفاع مشخص و قابل حل محاسبه کند.

واحد vh 

.hero {

    height:
        100vh;

}

واحد vh نسبت به ارتفاع Viewport تعریف می‌شود. 

1vh = 1% از ارتفاع Viewport

بنابراین: 

100vh = ارتفاع کامل Viewport
در طراحی مدرن موبایل، استفاده از 100vh می‌تواند در بعضی شرایط با نوارهای مرورگر موبایل مشکل ایجاد کند. واحدهای جدید Viewport مانند dvh، svh و lvh برای مدیریت بهتر این شرایط معرفی شده‌اند.

واحد dvh 

.hero {

    min-height:
        100dvh;

}

dvh مخفف Dynamic Viewport Height است. این واحد ارتفاع Dynamic Viewport را در نظر می‌گیرد.

برای بخش‌هایی که باید تقریباً ارتفاع صفحه نمایش را پر کنند، 100dvh می‌تواند انتخاب مناسبی باشد.

واحد svh 

.hero {

    min-height:
        100svh;

}

svh مخفف Small Viewport Height است. این واحد بر اساس اندازه کوچک‌تر Viewport در نظر گرفته می‌شود.

واحد lvh 

.hero {

    min-height:
        100lvh;

}

lvh مخفف Large Viewport Height است. این واحد بر اساس اندازه بزرگ‌تر Viewport در نظر گرفته می‌شود.

استفاده از calc() 

.main {

    height:
        calc(
            100vh - 80px
        );

}

در این مثال ارتفاع عنصر برابر با ارتفاع Viewport منهای 80px خواهد بود.

مثال کاربردی 

.header {

    height:
        80px;

}


main {

    min-height:
        calc(
            100vh - 80px
        );

}

Property: min-height 

.box {

    min-height:
        300px;

}

min-height حداقل ارتفاع مجاز عنصر را مشخص می‌کند.

اگر محتوای عنصر بیشتر از این مقدار باشد، عنصر می‌تواند برای نمایش محتوا بیشتر شود.

مثال حرفه‌ای 

.hero {

    min-height:
        500px;

}

برخلاف Height ثابت، استفاده از min-height اجازه می‌دهد عنصر در صورت نیاز بلندتر شود.

Property: max-height 

.box {

    max-height:
        500px;

}

max-height حداکثر ارتفاع مجاز عنصر را مشخص می‌کند.

مثال با Overflow 

.description {

    max-height:
        300px;

    overflow:
        auto;

}

در این مثال اگر محتوای عنصر بیشتر از 300px شود، Scrollbar می‌تواند برای مشاهده ادامه محتوا ایجاد شود.

ترکیب min-height و max-height 

.box {

    height:
        auto;

    min-height:
        300px;

    max-height:

        auto;

svh مربوط به Small Viewport Height است و برای حالتی طراحی شده که فضای کوچک‌تر Viewport مبنا قرار بگیرد. 

.hero {

    min-height:
        100lvh;

}

lvh مربوط به Large Viewport Height است.

min-height در Flexbox 

.container {

    display:
        flex;

    min-height:
        400px;

    align-items:
        center;

}

در این مثال Container حداقل 400px ارتفاع دارد و آیتم‌ها با استفاده از align-items در محور Cross قرار می‌گیرند.

min-height در Grid 

.grid {

    display:
        grid;

    min-height:
        500px;

}

می‌توان حداقل ارتفاع کل Grid Container را تعیین کرد و سپس ارتفاع واقعی آن بر اساس محتوا و قوانین Grid مشخص شود.

.main {

    min-height:
        calc(
            100vh - 80px
        );

}

اگر Header مثلاً 80px ارتفاع داشته باشد، می‌توان فضای باقی‌مانده Viewport را برای بخش اصلی صفحه در نظر گرفت.

استفاده از min() 

.box {

    min-height:
        min(
            600px,
            100vh
        );

}

تابع min() کوچک‌ترین مقدار محاسبه‌شده را انتخاب می‌کند.

استفاده از max() 

.box {

    min-height:
        max(
            300px,
            50vh
        );

}

تابع max() بزرگ‌ترین مقدار را انتخاب می‌کند.

استفاده از clamp() 

.hero {

    min-height:
        clamp(
            400px,
            70vh,
            800px
        );

}

در این مثال مقدار حداقل ارتفاع با سه مقدار کنترل می‌شود:

  • حداقل: 400px
  • مقدار ترجیحی: 70vh
  • حداکثر: 800px

min-height و محتوای زیاد 

.card {

    min-height:
        300px;

}

اگر محتوای کارت فقط 100px فضا نیاز داشته باشد، کارت حداقل 300px خواهد بود. اما اگر محتوا به 500px فضا نیاز داشته باشد، کارت می‌تواند تا 500px رشد کند.

اشتباهات رایج

  1. اشتباه گرفتن min-height با height.
  2. استفاده بیش از حد از ارتفاع‌های ثابت.
  3. استفاده از 100vh بدون توجه به Viewportهای موبایل.
  4. تعیین min-height بسیار بزرگ برای صفحات کوچک.
  5. تصور اینکه min-height مانع رشد عنصر می‌شود.

        100dvh;

        flex;

    flex-direction:
        column;

        1;

  • ساخت Heroهای انعطاف‌پذیر

  • Responsive Design
  • ساخت Layoutهای Flex و Grid
  • کنترل بهتر Viewport در موبایل

Property: max-height

max-height چیست؟

Property مربوط به max-height حداکثر ارتفاعی را مشخص می‌کند که یک عنصر می‌تواند داشته باشد. برخلاف min-height که حداقل ارتفاع را مشخص می‌کند، max-height برای تعیین سقف ارتفاع عنصر استفاده می‌شود.

نکته بسیار مهم:

max-height به این معنی نیست که محتوای عنصر همیشه داخل این ارتفاع جا می‌شود. اگر محتوا بیشتر از حداکثر ارتفاع باشد، باید رفتار Overflow را نیز بررسی کنیم.

Syntax 

selector {

    max-height: value;

}

مقدار px 

.box {

    max-height:
        300px;

}

در این مثال ارتفاع عنصر نمی‌تواند از 300px بیشتر شود.

مقدار درصدی 

.box {

    max-height:
        50%;

}

مقدار درصدی معمولاً نسبت به ارتفاع Containing Block محاسبه می‌شود. بنابراین برای استفاده قابل پیش‌بینی از درصد، ارتفاع مرجع باید مشخص باشد.

مقدار none 

.box {

    max-height:
        none;

}

مقدار none یعنی برای ارتفاع، محدودیت حداکثری تعریف نشده است. این مقدار برای برداشتن محدودیت max-height بسیار مهم است.

مقدار 0 

.box {

    max-height:
        0;

}

در این حالت حداکثر ارتفاع عنصر صفر می‌شود. اگر محتوا وجود داشته باشد، بسته به Overflow ممکن است محتوا بیرون بزند یا مخفی شود.

مقدارهای Global

مقدار توضیح
inherit مقدار max-height را از عنصر والد به ارث می‌برد.
initial مقدار اولیه Property را اعمال می‌کند.
unset بسته به شرایط مانند inherit یا initial رفتار می‌کند.
revert مقدار را به وضعیت مناسب قبلی Cascade برمی‌گرداند.
revert-layer مقدار را نسبت به Cascade Layer قبلی برمی‌گرداند.

تفاوت max-height با height 

.box {

    height:
        300px;

}

height ارتفاع مشخصی برای عنصر تعیین می‌کند. اما: 

.box {

    max-height:
        300px;

}

max-height فقط سقف ارتفاع را تعیین می‌کند.

به زبان ساده:

height → ارتفاع مشخص
min-height → حداقل ارتفاع
max-height → حداکثر ارتفاع

max-height و Overflow

یکی از مهم‌ترین کاربردهای max-height زمانی است که می‌خواهیم ارتفاع یک Container را محدود کنیم. 

.box {

    max-height:
        300px;

    overflow:
        auto;

}

در این مثال، اگر محتوای داخل Box بیشتر از 300px شود، مرورگر در صورت نیاز Scroll ایجاد می‌کند.

مخفی کردن محتوای اضافی 

.box {

    max-height:
        300px;

    overflow:
        hidden;

}

با overflow: hidden قسمت‌هایی از محتوا که خارج از محدوده قابل نمایش باشند، دیده نمی‌شوند.

ایجاد Scroll عمودی 

.messages {

    max-height:
        400px;

    overflow-y:
        auto;

}

این الگو برای بخش‌هایی مانند:

  • لیست پیام‌ها
  • لیست اعلان‌ها
  • پنل مدیریت
  • لیست محصولات
  • بخش نظرات

استفاده از vh 

.sidebar {

    max-height:
        100vh;

}

این روش می‌تواند ارتفاع Sidebar را به ارتفاع Viewport محدود کند.

واحدهای مدرن Viewport 

.sidebar {

    max-height:
        100dvh;

}

dvh برای Dynamic Viewport Height استفاده می‌شود و در طراحی‌های Responsive مدرن مخصوصاً روی دستگاه‌های موبایل کاربرد دارد. 

.sidebar {

    max-height:
        100svh;

}

svh بر اساس Small Viewport Height محاسبه می‌شود. 

.sidebar {

    max-height:
        100lvh;

}

lvh بر اساس Large Viewport Height محاسبه می‌شود.

استفاده از calc() 

.content {

    max-height:
        calc(
            100vh - 80px
        );

}

می‌توان با calc() حداکثر ارتفاع را نسبت به بخش‌های دیگر صفحه محاسبه کرد.

استفاده از min() 

.box {

    max-height:
        min(
            600px,
            80vh
        );

}

تابع min() کوچک‌ترین مقدار را انتخاب می‌کند.

استفاده از max() 

.box {

    max-height:
        max(
            300px,
            50vh
        );

}

تابع max() بزرگ‌ترین مقدار محاسبه‌شده را انتخاب می‌کند.

استفاده از clamp() 

.box {

    max-height:
        clamp(
            300px,
            60vh,
            700px
        );

}

clamp() امکان تعریف مقدار ترجیحی همراه با حداقل و حداکثر را فراهم می‌کند.

max-height در Flexbox 

.panel {

        flex;

    flex-direction:
        column;

    max-height:
        500px;

    overflow:
        auto;

}

این الگو برای ساخت پنل‌هایی که نباید بیش از مقدار مشخصی ارتفاع داشته باشند بسیار کاربردی است.

max-height در Grid 

.grid-container {

    display:
        grid;

    max-height:
        600px;

    overflow:
        auto;

}

استفاده در بخش‌های باز و بسته‌شونده 

.description {

    max-height:
        0;

    overflow:
        hidden;

}

    max-height:
        500px;

}

این تکنیک در بعضی پیاده‌سازی‌های Accordion و بخش‌های Expand/Collapse استفاده می‌شود.

نکته حرفه‌ای:

استفاده از max-height برای Animation باز و بسته شدن می‌تواند محدودیت‌هایی داشته باشد؛ زیرا مقدار دقیق ارتفاع محتوا همیشه مشخص نیست. در پروژه‌های مدرن باید با توجه به نیاز پروژه، روش مناسب Animation انتخاب شود.

اشتباهات رایج

  1. استفاده از max-height بدون تعیین Overflow مناسب.
  2. تصور اینکه max-height محتوای اضافی را خودکار مخفی می‌کند.
  3. استفاده از درصد بدون داشتن ارتفاع مرجع مشخص.
  4. استفاده از مقدار بسیار کوچک برای Containerهای دارای محتوای زیاد.
  5. استفاده بی‌دلیل از max-height در Layoutهای کاملاً انعطاف‌پذیر.

list-style و استایل‌دهی حرفه‌ای به لیست‌ها

لیست‌ها در HTML

در HTML معمولاً برای ایجاد لیست از عناصر <ul> و <ol> استفاده می‌کنیم. CSS به ما اجازه می‌دهد ظاهر Marker، محل قرارگیری آن، نوع شماره‌گذاری و بسیاری از جزئیات ظاهری لیست را کنترل کنیم.

لیست بدون ترتیب — ul 

<ul>

    <li>
        HTML
    </li>

    <li>
        CSS
    </li>

    <li>
        JavaScript
    </li>

</ul>

به‌صورت پیش‌فرض مرورگر معمولاً برای آیتم‌های ul از Marker دایره‌ای استفاده می‌کند.

لیست مرتب — ol 

<ol>

    <li>
        HTML
    </li>

    <li>
        CSS
    </li>

    <li>
        JavaScript
    </li>

</ol>

در لیست ol آیتم‌ها به‌صورت مرتب و شماره‌گذاری‌شده نمایش داده می‌شوند.

list-style چیست؟

Property مربوط به list-style یک Shorthand Property است که می‌تواند چند ویژگی مربوط به Marker لیست را به‌صورت هم‌زمان تنظیم کند.

Syntax 

ul {

    list-style:
        type
        position
        image;

}

مثال 

ul {

    list-style:
        square
        outside;

}

در این مثال نوع Marker برابر square و موقعیت آن outside است.

list-style-type

Property مربوط به list-style-type نوع Marker لیست را مشخص می‌کند.

ul {

    list-style-type:
        value;

مقدار توضیح
disc دایره توپر.
circle دایره توخالی.
square مربع توپر.
none Marker نمایش داده نمی‌شود.

        none;

مقدار نمونه

این Property مشخص می‌کند Marker نسبت به محتوای آیتم لیست در چه موقعیتی قرار بگیرد.

مقدار توضیح

  • list-style-position محل Marker را مشخص می‌کند.
  • list-style-image امکان استفاده از تصویر به‌عنوان Marker را فراهم می‌کند.
  • ::marker امکان کنترل بخشی از ظاهر Marker را فراهم می‌کند.
  • CSS Counterها برای شماره‌گذاری‌های سفارشی و پویا بسیار قدرتمند هستند.
فصل ۴۲ به پایان رسید. حالا می‌توانی ظاهر لیست‌های ساده، Navigationها و حتی شماره‌گذاری‌های چندسطحی را با CSS کنترل کنی.

استایل‌دهی حرفه‌ای جدول‌ها (Tables)

مقدمه

جدول‌ها برای نمایش اطلاعات ساختاریافته مانند قیمت‌ها، مشخصات محصولات، نتایج، گزارش‌ها و داده‌های آماری استفاده می‌شوند. CSS امکانات زیادی برای کنترل ظاهر جدول‌ها در اختیار ما قرار می‌دهد.

Property: border-collapse

این Property مشخص می‌کند که Borderهای سلول‌های جدول به صورت جداگانه نمایش داده شوند یا با یکدیگر ادغام شوند. 

table {

    border-collapse: value;

}

مقدارهای border-collapse

مقدار توضیح مثال
separate Border سلول‌ها جدا از یکدیگر نمایش داده می‌شوند. این مقدار پیش‌فرض است. border-collapse: separate;
collapse Borderهای مجاور سلول‌ها با یکدیگر ادغام می‌شوند. border-collapse: collapse;

مثال 

table {

    width: 100%;

    border-collapse:
        collapse;

}

Property: border-spacing

زمانی که border-collapse: separate استفاده شده باشد، این Property فاصله بین Borderهای سلول‌ها را مشخص می‌کند.

    border-collapse:
        separate;

    border-spacing:
        10px;

}

دو مقدار برای border-spacing

    border-spacing:
        10px 20px;

}

مقدار اول فاصله افقی و مقدار دوم فاصله عمودی را مشخص می‌کند.

table {

    table-layout:
        value;

مقدارهای table-layout

مقدار توضیح
auto مرورگر عرض ستون‌ها را بر اساس محتوای جدول محاسبه می‌کند. این مقدار پیش‌فرض است.

        fixed;

تصاویر و Media در CSS

مقدمه

تصاویر یکی از مهم‌ترین بخش‌های تقریباً تمام وب‌سایت‌ها هستند. اما استفاده صحیح از تصویر فقط به قرار دادن یک تگ <img> در HTML محدود نمی‌شود. CSS به ما اجازه می‌دهد اندازه، نسبت تصویر، نحوه قرارگیری، برش، موقعیت و نحوه نمایش تصویر را به شکل دقیق کنترل کنیم.

نکته مهم:

بهتر است خود تصویر را با HTML وارد صفحه کنیم و CSS را برای کنترل نحوه نمایش آن استفاده کنیم. یعنی وظیفه HTML ساختار و محتوای تصویر است و وظیفه CSS کنترل ظاهر و Layout آن.

کنترل عرض تصویر با width

Property width عرض عنصر را تعیین می‌کند. این Property برای تصاویر نیز قابل استفاده است. 

img {

    width:
        300px;

}

مقدارهای رایج width

مقدار توضیح مثال
auto مرورگر مقدار مناسب را محاسبه می‌کند. width: auto;
px عرض مشخص و ثابت. width: 300px;
% عرض نسبت به عنصر مرجع. width: 100%;
vw نسبت به عرض Viewport. width: 50vw;
max-content تلاش برای استفاده از اندازه محتوا. width: max-content;
min-content کوچک‌ترین اندازه مناسب محتوا. width: min-content;

تصویر Responsive

یکی از مهم‌ترین تکنیک‌ها برای طراحی Responsive این است که تصویر اجازه داشته باشد از عرض Container خود بزرگ‌تر نشود. 

img {

    max-width:
        100%;

    height:
        auto;

}

این الگو یکی از رایج‌ترین روش‌ها برای جلوگیری از بیرون زدن تصویر از Container است.

چرا height: auto؟

وقتی عرض تصویر تغییر می‌کند، استفاده از height: auto باعث می‌شود نسبت اصلی تصویر حفظ شود.

Property: height

Property height ارتفاع عنصر را مشخص می‌کند. 

img {

    height:
        250px;

}

مقدارهای مهم height

مقدار توضیح
auto ارتفاع بر اساس اندازه و نسبت محتوا محاسبه می‌شود.
px ارتفاع ثابت.
% ارتفاع نسبی نسبت به Containing Block در شرایط مناسب.
vh ارتفاع نسبت به Viewport.
min-content حداقل اندازه مناسب محتوا.
max-content اندازه مناسب برای نمایش محتوا بدون فشرده‌سازی غیرضروری.

Property: object-fit

یکی از مهم‌ترین Propertyها هنگام کار با تصاویر، object-fit است. این Property مشخص می‌کند محتوای replaced element مانند تصویر چگونه داخل Box تعیین‌شده قرار بگیرد. 

img {

    width:
        300px;

    height:
        200px;

    object-fit:
        value;

}

تمام مقدارهای مهم object-fit

مقدار توضیح کاربرد
fill تصویر کل Box را پر می‌کند. در صورت نیاز نسبت اصلی تصویر ممکن است تغییر کند. زمانی که پر شدن کامل Box مهم‌تر از حفظ نسبت است.
contain کل تصویر داخل Box قرار می‌گیرد و نسبت تصویر حفظ می‌شود. محصولات، لوگوها و تصاویری که نباید بریده شوند.
cover تصویر کل Box را پر می‌کند و نسبت تصویر حفظ می‌شود. ممکن است بخشی از تصویر بریده شود. کارت‌ها، Bannerها و تصاویر Hero.
none تصویر بدون تغییر اندازه متناسب، در اندازه اصلی خود قرار می‌گیرد. زمانی که نمی‌خواهیم تصویر Fit شود.
scale-down مرورگر بین none و contain گزینه کوچک‌تر را انتخاب می‌کند. زمانی که نمی‌خواهیم تصویر بزرگ‌تر از اندازه اصلی شود.

مثال object-fit: cover 

.card-image {

    width:
        100%;

    height:
        250px;

    object-fit:
        cover;

}

مثال object-fit: contain 

.product-image {

    width:
        100%;

    height:
        250px;

    object-fit:
        contain;

}
تفاوت مهم:

cover معمولاً باعث Crop شدن بخشی از تصویر می‌شود، اما contain تلاش می‌کند کل تصویر را نمایش دهد.

Property: object-position

وقتی از object-fit: cover استفاده می‌کنیم، ممکن است بخشی از تصویر بریده شود. Property object-position مشخص می‌کند کدام قسمت تصویر در Box موقعیت اصلی داشته باشد.

    object-fit:
        cover;

    object-position:
        value;

bottom قسمت پایین تصویر را در اولویت قرار می‌دهد.

کنترل تعامل کاربر و رفتار عناصر

مقدمه

CSS فقط برای تعیین رنگ، اندازه و Layout عناصر نیست. در بسیاری از پروژه‌های حرفه‌ای لازم است نحوه تعامل کاربر با عناصر صفحه را نیز کنترل کنیم. برای مثال می‌توانیم مشخص کنیم:

  • هنگام قرار گرفتن ماوس روی یک عنصر، Cursor چگونه نمایش داده شود.
  • آیا کاربر بتواند متن را انتخاب کند یا نه.
  • آیا یک عنصر بتواند رویدادهای ماوس را دریافت کند یا نه.
  • رنگ Cursor داخل Input چه باشد.
  • رنگ کنترل‌های فرم چگونه باشد.
  • آیا کاربر بتواند اندازه یک Textarea را تغییر دهد یا نه.
  • ظاهر پیش‌فرض بعضی کنترل‌های مرورگر چگونه نمایش داده شود.

Property: cursor

Property cursor شکل Cursor یا نشانگر ماوس را هنگام قرار گرفتن روی یک عنصر مشخص می‌کند. 

.button {

    cursor:
        pointer;

}

CSS Multi-column Layout

Multi-column چیست؟

CSS Multi-column Layout قابلیتی است که به ما اجازه می‌دهد محتوای متنی را به چند ستون تقسیم کنیم. این قابلیت برای مقاله‌ها، مجله‌های آنلاین، کتاب‌های دیجیتال و متن‌های طولانی بسیار کاربردی است.

column-count

با این Property می‌توانیم تعداد ستون‌های محتوا را مشخص کنیم. 

.article {

    column-count:
        3;

}

در مثال بالا محتوای داخل عنصر به سه ستون تقسیم می‌شود.

column-width

با استفاده از این Property می‌توانیم عرض مطلوب هر ستون را مشخص کنیم. 

.article {

    column-width:
        250px;

}

مرورگر بر اساس فضای موجود تصمیم می‌گیرد چند ستون ایجاد شود.

column-gap

فاصله بین ستون‌ها را مشخص می‌کند. 

.article {

    column-count:
        3;

    column-gap:
        40px;

}

column-rule

می‌توانیم بین ستون‌ها یک خط جداکننده ایجاد کنیم. 

.article {

    column-count:
        3;

    column-gap:
        30px;

    column-rule:
        1px solid #ddd;

}

column-rule-width 

.article {

    column-rule-width:
        2px;

}

    column-rule-style:
        dashed;

}

.article {

    column-rule:

column-span

با این Property می‌توانیم مشخص کنیم یک عنصر در تمام ستون‌ها گسترده شود. 

.article-title {

    column-span:
        all;

فصل ۴۷

Property: aspect-ratio

aspect-ratio چیست؟

Property به نام aspect-ratio نسبت عرض به ارتفاع یک Box را مشخص می‌کند. این Property به مرورگر اجازه می‌دهد هنگام محاسبه اندازه عنصر، نسبت مشخصی بین Width و Height حفظ کند.

برای مثال اگر نسبت یک عنصر 16 / 9 باشد، با تغییر عرض عنصر، ارتفاع آن نیز می‌تواند بر اساس همین نسبت محاسبه شود.

Syntax 

.box {

    aspect-ratio:
        16 / 9;

}

نسبت 1 به 1 

.square {

    width:
        300px;

    aspect-ratio:
        1 / 1;

}

در این مثال عنصر نسبت 1 به 1 دارد؛ بنابراین اگر Width برابر 300px باشد، Height نیز حدود 300px خواهد بود.

نسبت 16 به 9 

.video-box {

    width:
        100%;

    aspect-ratio:
        16 / 9;

}

نسبت 16 به 9 یکی از نسبت‌های بسیار رایج برای ویدئو، Thumbnail و تصاویر عریض است.

نسبت 4 به 3 

.image {

    width:
        100%;

    aspect-ratio:
        4 / 3;

}

نسبت 3 به 2 

.photo {

    width:
        100%;

    aspect-ratio:
        3 / 2;

}

نسبت‌های رایج

نسبت کاربرد رایج
1 / 1 تصاویر مربعی، Avatar و Card
4 / 3 تصاویر و Layoutهای سنتی
3 / 2 تصاویر عکاسی
16 / 9 ویدئو و تصاویر عریض
21 / 9 تصاویر بسیار عریض و Banner

استفاده از یک عدد 

.box {

    aspect-ratio:
        1;

}

زمانی که فقط یک عدد نوشته شود، همان عدد نسبت Width به Height را مشخص می‌کند. بنابراین: 

aspect-ratio: 1;

معادل یک نسبت 1 / 1 است.

نسبت با دو مقدار 

.box {

    aspect-ratio:
        16 / 9;

}

مقدار سمت چپ نسبت عرض و مقدار سمت راست نسبت ارتفاع را مشخص می‌کند.

استفاده از auto 

.box {

    aspect-ratio:
        auto;

}

مقدار auto اجازه می‌دهد مرورگر از نسبت ذاتی عنصر در مواردی که وجود دارد استفاده کند.

auto همراه با نسبت 

.image {

    aspect-ratio:
        auto 16 / 9;

}

این Syntax مخصوصاً برای عناصر جایگزین‌شونده مانند تصاویر می‌تواند اهمیت داشته باشد. مرورگر می‌تواند در شرایط مربوطه از نسبت ذاتی عنصر استفاده کند.

aspect-ratio همراه با width 

.card {

    width:
        400px;

    aspect-ratio:
        16 / 9;

}

در این حالت Width مشخص شده و Height می‌تواند بر اساس نسبت تعیین شود.

aspect-ratio همراه با height 

.card {

    height:
        200px;

    aspect-ratio:
        16 / 9;

}

اگر Height مشخص باشد، مرورگر می‌تواند Width را بر اساس نسبت محاسبه کند؛ البته سایر محدودیت‌های اندازه عنصر نیز در محاسبه نهایی مؤثر هستند.

aspect-ratio و width و height همزمان 

.box {

    width:
        400px;

    height:
        300px;

    aspect-ratio:
        16 / 9;

}
نکته مهم: اگر Width و Height هر دو به‌صورت مشخص و ناسازگار با نسبت تعیین شوند، نمی‌توان انتظار داشت aspect-ratio همیشه هر دو مقدار را تغییر دهد. قوانین اندازه‌گذاری CSS و سایر محدودیت‌های Layout در محاسبه نهایی نقش دارند.

فصل ۴۸

Property: content-visibility

content-visibility چیست؟

ویژگی content-visibility به مرورگر اجازه می‌دهد مشخص کند محتوای یک عنصر چگونه در فرآیند Layout و Rendering پردازش شود. این Property در صفحات بسیار طولانی می‌تواند به کاهش کار اولیه مرورگر کمک کند.

Syntax 

.section {

    content-visibility:
        auto;

}

مقدار visible 

.section {

    content-visibility:
        visible;

}

مقدار visible رفتار عادی عنصر را حفظ می‌کند. یعنی مرورگر محتوا را به شکل معمول پردازش و نمایش می‌دهد.

مقدار hidden 

.section {

    content-visibility:
        hidden;

}

با مقدار hidden محتوای عنصر در فرآیند Rendering نمایش داده نمی‌شود و مشابه این است که محتوا از نظر بصری پنهان شده باشد؛ اما تفاوت‌های مهمی با display: none دارد.

توجه:

content-visibility: hidden را نباید به‌عنوان جایگزین ساده display: none در تمام شرایط در نظر گرفت. رفتار Layout، دسترسی به محتوا و فرآیند Rendering می‌تواند متفاوت باشد.

مقدار auto 

.article-section {

    content-visibility:
        auto;

}

مهم‌ترین مقدار برای بهینه‌سازی، auto است. در این حالت مرورگر می‌تواند محتوایی را که فعلاً خارج از محدوده قابل مشاهده کاربر است، تا زمانی که لازم نباشد به‌طور کامل Render نکند.

استفاده در صفحه طولانی 

.chapter {

    content-visibility:
        auto;

}

فرض کن یک صفحه آموزشی دارای ده‌ها فصل و بخش طولانی باشد. می‌توان بعضی بخش‌ها را به‌گونه‌ای تنظیم کرد که مرورگر در ابتدای بارگذاری مجبور نباشد تمام محتوای خارج از Viewport را یک‌باره Render کند.

contain-intrinsic-size

هنگامی که از content-visibility: auto استفاده می‌کنیم، مرورگر ممکن است قبل از Render شدن واقعی محتوا اندازه دقیق آن را نداند. Property دیگری به نام contain-intrinsic-size می‌تواند یک اندازه تقریبی برای این حالت در اختیار مرورگر قرار دهد. 

.chapter {

    content-visibility:
        auto;

    contain-intrinsic-size:
        800px;

}

چرا contain-intrinsic-size مهم است؟

اگر مرورگر برای محتوای هنوز Render نشده اندازه مناسبی در اختیار نداشته باشد، تغییر اندازه Layout پس از Render شدن محتوا می‌تواند باعث جابه‌جایی بخش‌های صفحه شود. تعیین یک اندازه ذاتی تقریبی می‌تواند به کاهش این مشکل کمک کند.

مثال حرفه‌ای برای مقالات 

.article-section {

    content-visibility:
        auto;

    contain-intrinsic-size:
        600px;

    padding-block:
        40px;

}

.product-card {

    content-visibility:
        auto;

    contain-intrinsic-size:
        300px;

}

اگر صفحه تعداد بسیار زیادی Card داشته باشد، این روش می‌تواند به مرورگر کمک کند تا کار Rendering غیرضروری را کاهش دهد.

تفاوت display: none و content-visibility

ویژگی رفتار

content-visibility: hidden Rendering محتوای عنصر پنهان می‌شود، اما رفتار آن با display: none یکسان نیست.
content-visibility: auto مرورگر می‌تواند Rendering محتوای خارج از محدوده دید را به زمان مناسب‌تری موکول کند.

نکته حرفه‌ای:

در کنار آن، contain-intrinsic-size می‌تواند برای ارائه یک اندازه تقریبی به مرورگر مفید باشد.

فصل ۴۹

CSS Containment و Property: contain

CSS Containment چیست؟

CSS Containment مجموعه‌ای از قابلیت‌های CSS است که به مرورگر اجازه می‌دهد محدوده تأثیر یک عنصر را بهتر مشخص کند. به زبان ساده، می‌توانیم به مرورگر بگوییم که تغییرات یک بخش از صفحه تا حد مشخصی مستقل از بخش‌های دیگر در نظر گرفته شود.

این قابلیت مخصوصاً در پروژه‌های بزرگ، Componentهای پیچیده، لیست‌های طولانی و Layoutهای بزرگ می‌تواند برای بهبود Performance مفید باشد.

Property: contain

Property contain برای اعمال Containment روی یک عنصر استفاده می‌شود.

Syntax پایه 

.component {

    contain:
        layout;

}

مقدار none 

.component {

    contain:
        none;

}

مقدار none هیچ Containment خاصی را اعمال نمی‌کند. این مقدار رفتار پیش‌فرض Property است.

مقدار layout 

.component {

    contain:
        layout;

}

مقدار layout باعث ایجاد Layout Containment می‌شود. این کار به مرورگر کمک می‌کند محاسبات Layout مربوط به عنصر را تا حد مشخصی مستقل از بیرون آن در نظر بگیرد.

مقدار paint 

.component {

    contain:
        paint;

}

با paint Painting محتوای عنصر نسبت به محدوده Containment محدود می‌شود. در نتیجه محتوای عنصر نمی‌تواند به شکل معمول خارج از محدوده Containing Box Paint شود.

مقدار size 

.component {

    contain:
        size;

}

مقدار size باعث می‌شود اندازه عنصر در محاسبات اندازه‌گذاری، مستقل‌تر در نظر گرفته شود. این مقدار نیاز به دقت بیشتری دارد، زیرا اگر اندازه مناسب برای عنصر مشخص نشده باشد، ممکن است نتیجه Layout با چیزی که انتظار داریم متفاوت شود.

مقدار style 

.component {

    contain:
        style;

}

Containment مربوط به Style باعث می‌شود برخی تأثیرات Style مربوط به عنصر و محتوای آن محدود شوند.

چند مقدار همزمان 

.component {

    contain:
        layout paint;

}

می‌توان چند نوع Containment را همزمان استفاده کرد.

ترکیب size و layout 

.component {

    contain:
        size layout;

}

ترکیب چند نوع Containment 

.component {

    contain:
        size layout paint style;

با این روش می‌توان چند محدودیت مختلف را برای یک عنصر اعمال کرد.

مقدار strict 

.component {

    contain:
        strict;

}

مقدار strict یک شکل فشرده برای اعمال مجموعه‌ای از Containmentهای اصلی است. به‌صورت مفهومی شامل Size، Layout، Paint و Style می‌شود.

مقدار content 

.component {

    contain:
        content;

}

مقدار content نیز یک حالت ترکیبی است که برای محدود کردن اثرات Layout، Paint و Style محتوای عنصر کاربرد دارد.

تفاوت content و strict

Containment و Performance

یکی از اهداف مهم CSS Containment این است که مرورگر بتواند در هنگام تغییرات Layout، Style یا Paint، از انجام محاسبات غیرضروری در بخش‌های کاملاً نامرتبط صفحه جلوگیری کند.

نکته حرفه‌ای:

contain یک ابزار جادویی برای سریع کردن تمام سایت‌ها نیست. اگر بدون شناخت Layout از آن استفاده شود، ممکن است اندازه‌گذاری یا نمایش عناصر با انتظار ما متفاوت شود. ابتدا Performance را اندازه‌گیری کن، سپس Containment را در بخش‌هایی که واقعاً مستقل هستند آزمایش کن.

contain و overflow 

.box {

    contain:
        paint;

    overflow:
        hidden;

}

در این حالت هم Containment مربوط به Paint و هم کنترل Overflow را داریم. اما این دو Property یک مفهوم ندارند:

  • overflow نحوه برخورد با محتوای خارج از Box را کنترل می‌کند.
  • contain محدوده اثرگذاری و پردازش بخش‌هایی از عنصر را کنترل می‌کند.

contain و position 

.component {

        relative;

فصل ۵۰

Property: isolation و Stacking Context

isolation چیست؟

Property به نام isolation برای مشخص کردن این موضوع استفاده می‌شود که آیا یک عنصر باید یک Stacking Context مستقل ایجاد کند یا خیر.

این Property زمانی اهمیت زیادی پیدا می‌کند که در یک صفحه چندین عنصر با z-index، position، pseudo-element، blend mode و لایه‌های مختلف داشته باشیم.

Syntax 

.container {

    isolation:
        isolate;

}

مقدار auto 

.container {

    isolation:
        auto;

}

مقدار auto رفتار پیش‌فرض است. در این حالت عنصر الزاماً یک Stacking Context جدید فقط به دلیل استفاده از Property isolation ایجاد نمی‌کند.

مقدار isolate 

.container {

    isolation:
        isolate;

}

مقدار isolate باعث می‌شود عنصر یک Stacking Context مستقل ایجاد کند.

نکته مهم:

isolation: isolate به این معنی نیست که عنصر از تمام قوانین Layering و Stacking صفحه جدا می‌شود. بلکه یک Stacking Context مستقل ایجاد می‌کند و عناصر داخل آن Context در همان محدوده مدیریت می‌شوند.

Stacking Context چیست؟

مرورگر عناصر صفحه را فقط به صورت ساده «روی هم» قرار نمی‌دهد. برای مدیریت ترتیب لایه‌ها، گروه‌هایی به نام Stacking Context وجود دارند.

هر Stacking Context را می‌توان مانند یک فضای لایه‌ای مستقل تصور کرد که فرزندان آن در داخل همان فضا نسبت به یکدیگر مرتب می‌شوند.

z-index چیست؟ 

.box {

    position:
        relative;

    z-index:
        10;

}

z-index برای کنترل ترتیب قرارگیری لایه‌ها در محور Z استفاده می‌شود.

یک اشتباه رایج با z-index 

.parent {

    position:
        relative;

    z-index:
        1;

}


.child {

    position:
        relative;

    z-index:
        999999;

}

عدد بسیار بزرگ 999999 لزوماً باعث نمی‌شود عنصر child روی تمام عناصر صفحه قرار بگیرد. چون child ابتدا در Stacking Context والد خودش قرار دارد.

مثال Stacking Context 

.parent {

    position:
        relative;

    z-index:
        1;

}


.child {

    position:
        absolute;

    z-index:
        999;

}


.other {

    position:
        relative;

    z-index:
        2;

}

حتی اگر child دارای z-index: 999 باشد، ممکن است کل گروه والد z-index: 1 زیر گروه دیگری با z-index: 2 قرار بگیرد.

ایجاد Stacking Context با isolation 

.card {

    isolation:
        isolate;

}

        0;

        -1;

مثال کارت با لایه پس‌زمینه

  • بعضی ویژگی‌های مربوط به blending

ویژگی وظیفه

        isolate;

writing-mode، direction و text-orientation

writing-mode چیست؟

Property به نام writing-mode جهت جریان نوشتار و نحوه قرارگیری خطوط متن را مشخص می‌کند. برخلاف تصور رایج، این Property فقط برای زبان‌های آسیایی نیست و در طراحی Layoutهای خاص نیز کاربرد دارد.

Syntax 

.text {

    writing-mode:
        vertical-rl;

}

مقدارهای writing-mode

مقدار توضیح
horizontal-tb نوشتار افقی است و خطوط از بالا به پایین قرار می‌گیرند.
vertical-rl نوشتار عمودی است و خطوط از راست به چپ پیش می‌روند.
vertical-lr نوشتار عمودی است و خطوط از چپ به راست پیش می‌روند.
sideways-rl در محیط‌هایی که پشتیبانی می‌شوند، حروف به صورت چرخیده در جهت راست به چپ نمایش داده می‌شوند.
sideways-lr در محیط‌هایی که پشتیبانی می‌شوند، حروف به صورت چرخیده در جهت چپ به راست نمایش داده می‌شوند.
نکته:

مقدار پیش‌فرض horizontal-tb است. در پروژه‌های معمول فارسی، معمولاً نیازی به تغییر writing-mode نداریم.

horizontal-tb

    writing-mode:
        horizontal-tb;

    writing-mode:
        vertical-rl;

}

vertical-lr

    writing-mode:
        vertical-lr;

Property به نام filter برای اعمال افکت‌های گرافیکی روی یک عنصر استفاده می‌شود. با استفاده از Filter می‌توان تصویر، متن یا سایر عناصر را تار کرد، روشنایی و کنتراست آن‌ها را تغییر داد، رنگ‌ها را تنظیم کرد و افکت‌های مختلفی ایجاد کرد.

.image {

    filter:
        blur(5px);

}
نکته:

filter روی خود عنصر و محتوای رندرشده آن اعمال می‌شود. به همین دلیل اگر روی یک عنصر دارای متن Filter اعمال کنیم، متن نیز می‌تواند تحت تأثیر قرار بگیرد.

مقدار none 

.element {

    filter:
        none;

}

هیچ Filterی روی عنصر اعمال نمی‌شود. این مقدار مقدار اولیه filter است.

blur()

تابع blur() باعث تار شدن عنصر می‌شود. 

.image {

    filter:
        blur(5px);

مقدار داخل پرانتز معمولاً یک طول مانند px است. هرچه مقدار بیشتر باشد، میزان Blur بیشتر می‌شود.

مقدارهای بیشتر از 1 روشنایی را افزایش می‌دهند.

.image {

.image {

        grayscale(1);

تابع opacity() میزان شفافیت عنصر را کنترل می‌کند. 

.image {

    filter:
        opacity(.5);

}

.box {

    opacity:
        .5;

}

تابع saturate() شدت و اشباع رنگ‌ها را کنترل می‌کند. 

.image {

}

مقدار 1 حالت اصلی است. مقدار کمتر از 1 رنگ‌ها را کم‌اشباع‌تر می‌کند. مقدار بیشتر از 1 رنگ‌ها را شدیدتر می‌کند.

.image {

backdrop-filter چیست؟

Property به نام backdrop-filter افکت را روی محتوایی که پشت یک عنصر قرار دارد اعمال می‌کند. این ویژگی برای ساخت افکت‌هایی مانند شیشه مات یا Glassmorphism بسیار کاربرد دارد.

مثال ساده

    backdrop-filter:
        blur(10px);

}

توجه کن که برای مشاهده این افکت، معمولاً عنصر باید مقداری شفافیت داشته باشد تا محتوای پشت آن دیده شود.

Glassmorphism

        blur(12px)
        brightness(.9);

}

filter روی خود عنصر و محتوای رندرشده آن
backdrop-filter روی محتوای پشت عنصر

Writing Modes و جهت نوشتار

CSS فقط برای تعیین ظاهر عناصر نیست. می‌توان با CSS جهت جریان متن و Layout را نیز کنترل کرد. این موضوع برای طراحی سایت‌های چندزبانه، زبان فارسی، عربی، انگلیسی و زبان‌هایی که به‌صورت عمودی نوشته می‌شوند اهمیت زیادی دارد.

Property: direction

Property direction جهت نوشتار متن را مشخص می‌کند. این Property به‌خصوص برای زبان‌های راست‌به‌چپ و چپ‌به‌راست کاربرد دارد.

Syntax 

selector {

    direction:
        value;

}

مقدار ltr 

.english {

    direction:
        ltr;

}

ltr مخفف Left To Right است. یعنی جهت نوشتار از چپ به راست خواهد بود. این مقدار برای زبان‌هایی مانند انگلیسی مناسب است.

مقدار rtl 

.persian {

    direction:
        rtl;

}

rtl مخفف Right To Left است. یعنی جهت نوشتار از راست به چپ خواهد بود. برای فارسی و عربی بسیار کاربردی است.

مقدار inherit 

.child {

    direction:
        inherit;

}

مقدار inherit باعث می‌شود عنصر مقدار direction را از والد خود به ارث ببرد.

مثال برای یک سایت فارسی 

html {

    direction:
        rtl;

}

در یک سایت فارسی معمولاً بهتر است جهت کلی سند را با ویژگی dir="rtl" در HTML مشخص کنیم. CSS می‌تواند برای کنترل بخش‌های خاص صفحه استفاده شود.

Property: writing-mode

Property writing-mode مشخص می‌کند متن و جریان نوشتار در چه جهتی قرار بگیرد. این Property می‌تواند جریان متن را افقی یا عمودی کند.

Syntax 

selector {

    writing-mode:
        value;

}

مقدار horizontal-tb 

.box {

    writing-mode:
        horizontal-tb;

}

متن به‌صورت افقی نمایش داده می‌شود و خطوط متن از بالا به پایین قرار می‌گیرند. این مقدار برای حالت معمول نوشتار در صفحات وب استفاده می‌شود.

مقدار vertical-rl 

.box {

    writing-mode:
        vertical-rl;

}

متن به‌صورت عمودی جریان پیدا می‌کند و خطوط از سمت راست به سمت چپ قرار می‌گیرند. این حالت برای بعضی زبان‌های شرق آسیا کاربرد زیادی دارد.

مقدار vertical-lr 

.box {

    writing-mode:
        vertical-lr;

}

متن به‌صورت عمودی جریان پیدا می‌کند، اما ترتیب خطوط از چپ به راست خواهد بود.

مقدار sideways-rl 

.box {

    writing-mode:
        sideways-rl;

}

محتوا در حالت عمودی قرار می‌گیرد و حروف به‌صورت چرخیده نمایش داده می‌شوند.

مقدار sideways-lr 

.box {

    writing-mode:
        sideways-lr;

}

مشابه sideways-rl است، اما جهت جریان متفاوت است.

Property: text-orientation

Property text-orientation نحوه قرارگیری حروف را هنگام استفاده از Writing Modeهای عمودی کنترل می‌کند.

مقدار mixed 

.vertical-text {

    writing-mode:
        vertical-rl;

    text-orientation:
        mixed;

}

مقدار mixed اجازه می‌دهد حروف بسته به نوع سیستم نوشتاری جهت مناسب خود را داشته باشند.

مقدار upright 

.vertical-text {

    writing-mode:
        vertical-rl;

    text-orientation:
        upright;

}

در حالت upright حروف به‌صورت ایستاده نمایش داده می‌شوند.

مقدار sideways 

.vertical-text {

    writing-mode:
        vertical-rl;

    text-orientation:
        sideways;

}

حروف در حالت چرخیده قرار می‌گیرند.

مثال ساخت متن عمودی 

.vertical-title {

    writing-mode:
        vertical-rl;

    text-orientation:
        mixed;

    height:
        250px;

}

ترکیب direction و writing-mode 

.vertical-box {

    writing-mode:
        vertical-rl;

    direction:
        rtl;

}

این دو Property می‌توانند در کنار یکدیگر برای کنترل دقیق‌تر جهت جریان محتوا استفاده شوند.

Block Axis و Inline Axis

در CSS مدرن بهتر است به‌جای اینکه همیشه ذهن خود را به top، bottom، left و right محدود کنیم، با مفاهیم Block Axis و Inline Axis نیز آشنا باشیم.

  • Inline Axis
    معمولاً جهت حرکت متن در یک خط است.
  • Block Axis
    جهتی است که خطوط یا Blockها در آن روی یکدیگر قرار می‌گیرند.

مثال حرفه‌ای — عنوان عمودی کنار کارت 

.card {

    display:
        flex;

    gap:
        20px;

}


.card-title {

    writing-mode:
        vertical-rl;

    text-orientation:
        mixed;

}

مقایسه مقدارهای writing-mode

مقدار کاربرد
horizontal-tb حالت افقی معمولی؛ خطوط از بالا به پایین.
vertical-rl نوشتار عمودی با جریان خطوط از راست به چپ.
vertical-lr نوشتار عمودی با جریان خطوط از چپ به راست.
sideways-rl نوشتار عمودی با حروف چرخیده و جهت rl.
sideways-lr نوشتار عمودی با حروف چرخیده و جهت lr.
نکته حرفه‌ای:

برای تعیین جهت کلی یک سند فارسی، استفاده از <html dir="rtl"> معمولاً انتخاب مناسبی است. در پروژه‌های چندزبانه نیز بهتر است جهت هر بخش بر اساس زبان همان محتوا به‌صورت آگاهانه مدیریت شود.
